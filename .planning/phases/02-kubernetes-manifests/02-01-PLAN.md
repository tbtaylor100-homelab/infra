    CRITICAL sync wave: annotation argocd.argoproj.io/sync-wave: "-1" ensures this resource is created after the namespace (wave -2) but before the Deployment (wave 0, default).

    The target Secret named aiostreams-secret will be created by ESO in the aiostreams namespace and consumed by the Deployment in Plan 02 via envFrom.secretRef.name: aiostreams-secret.

|----------|-------------|
| git repo → cluster | ArgoCD pulls manifests from Forgejo; any file committed here becomes a cluster resource |
| cluster → OpenBao | ExternalSecret operator authenticates to OpenBao via Kubernetes auth; credentials never appear in manifests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | external-secret.yaml | mitigate | Only remoteRef paths in manifest — no secret values. creationPolicy: Owner ensures ESO owns the resulting Secret. Verify: `git log -p --all -S "apiKey"` returns no matches after commit. |
| T-02-02 | Tampering | configmap.yaml (WHITELISTED_REGEX_PATTERNS) | mitigate | ConfigMap is version-controlled in git — all changes have an audit trail. Regex syntax validated by AIOStreams on startup (invalid JSON rejected). |
| T-02-03 | Availability | external-secret.yaml | mitigate | sync-wave: "-1" prevents ExternalSecret creation before namespace exists. Phase 1 prerequisite (eso-policy extended) verified before execution. |
</threat_model>
