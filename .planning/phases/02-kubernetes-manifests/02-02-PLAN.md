<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Deployment env → pod process | envFrom injects values at pod start; secrets must come from aiostreams-secret (ESO-managed), not inline values |
| ArgoCD → cluster | ArgoCD applies manifests from main branch; prune=true means removed files delete cluster resources |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Information Disclosure | deployment.yaml env section | mitigate | SECRET_KEY and FORCED_SERVICE_CREDENTIALS injected via envFrom.secretRef only — no inline env values for credentials. Verify: `grep -i 'secret_key\|forced_service' kubernetes/aiostreams/deployment.yaml` returns no matches on the env: block (only on the envFrom secretRef name). |
| T-02-05 | Availability | deployment.yaml probes | mitigate | Both liveness and readiness probes on GET /api/v1/status port 3000 detect app-level hangs (TCP probe would miss these). failureThreshold: 3 / 2 prevents premature restarts during slow startup. |
| T-02-06 | Availability | deployment.yaml PVC | mitigate | PVC uses local-path StorageClass (persistent across pod restarts). replicas: 1 prevents ReadWriteOnce binding conflicts. 10Gi prevents SQLite write failures from disk exhaustion. |
| T-02-07 | Elevation of Privilege | argocd/apps/aiostreams.yaml | accept | selfHeal: true enforces GitOps — manual kubectl edits are reverted automatically. prune: true removes stale resources. Both are intentional controls, not threats. Risk: malicious commit to main could deploy harmful manifests; mitigated by Forgejo access control (out of scope for this phase). |
</threat_model>
