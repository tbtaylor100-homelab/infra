    **Title:** "# Runbook: Set Up AIOStreams After Deployment"

    **Opening paragraph:** State this runbook covers post-deploy UI configuration of AIOStreams v2.29.5 (version-pin required per D-05). AIOStreams must already be deployed and reachable.

    **Note block:** Link to provision-aiostreams-secrets.md — "This runbook begins where provision-aiostreams-secrets.md ends. Complete secrets provisioning and Phase 2 Kubernetes deployment before continuing."

    **## Prerequisites:**
    - AIOStreams pod is running and reachable: `curl -s http://192.168.1.205:3000/api/v1/status` returns HTTP 200
    - ExternalSecret has synced: `kubectl get externalsecret -n aiostreams aiostreams-secret` shows READY: True
    - Stremio is installed on a LAN-connected device
    - AIOStreams UI accessible at: http://192.168.1.205:3000
    - Cross-link: secrets provisioned per homelab-knowledge/runbooks/provision-aiostreams-secrets.md

    **## Steps:**

    ### 1. Verify Real-Debrid is connected
    Navigate: Services menu → Real-Debrid row → click cogwheel icon (⚙️)
    The API Key field should be pre-populated from FORCED_SERVICE_CREDENTIALS env var.
    Look for "Connected" status indicator (green checkmark or status text).
    If showing "Disconnected": see Troubleshooting below.

    ### 2. Install the Torrentio addon
    Navigate: Addons → Marketplace tab → Search "Torrentio"
    If not found in search: use the custom manifest URL field and paste:
    `https://torrentio.strem.fun/manifest.json`
    Click Install. Verify addon appears in the Installed tab.

    ### 3. Activate the regex exclusion filter
    Navigate: Filters → Regex Patterns section
    Note: WHITELISTED_REGEX_PATTERNS is pre-configured via ConfigMap with the pattern
    `["/(WEB-DL|AMZN|DSNP|YTS|RARBG|EZTV)/i"]`. The operator does NOT need to re-enter the regex.
    Enable the "Use Regex Filters" toggle (or equivalent UI control).
    Expected: Stremio search results will now exclude streams matching the pre-configured tags.

    ### 4. Add AIOStreams as a Stremio addon source
    In Stremio (on your LAN device):
    Go to: Settings → Addons → Add addon source
    Enter the AIOStreams manifest URL: `http://192.168.1.205:3000/manifest.json`
    Stremio will list available addons from AIOStreams (including the configured Torrentio instance).

    ### 5. Verify version (optional)
    Confirm the running version matches these runbook steps:
    `kubectl exec -n aiostreams deployment/aiostreams -- curl -s http://localhost:3000/api/v1/status | jq '.version'`
    Expected: "v2.29.5". If a different version is returned, menu names and field locations may differ.

    **## Troubleshooting:**
    Table with Symptom | Likely cause columns (from RESEARCH.md Pitfall 1-4):
    - Real-Debrid shows Disconnected | ESO sync failure; check ExternalSecret status and restart pod
    - Regex Patterns section not visible in Filters | ADDON_PASSWORD may be required or pod needs restart; verify REGEX_FILTER_ACCESS=all env var
    - Torrentio not found in Marketplace | Use manifest URL https://torrentio.strem.fun/manifest.json directly
    - Pod shows "Disconnected" after ESO sync confirms SecretSynced | Restart pod to force env var re-read: kubectl rollout restart deployment aiostreams -n aiostreams
    - UI menu names don't match this runbook | Version changed; run version check Step 5 and verify against current AIOStreams docs
    - Stremio shows "no results" after addon add | Verify Torrentio manifest is reachable: curl https://torrentio.strem.fun/manifest.json
