    **# ADR-017: Deploy AIOStreams on K3s as a Stremio Filtering Proxy**

    **## Status**
    Accepted

    **## Date**
    2026-05-13

    **## Context**
    Narrative covering:
    - What AIOStreams is (a self-hosted addon aggregator for Stremio that filters debrid service responses)
    - The May 2026 Real-Debrid blocking incident: Real-Debrid implemented content filtering on or around 2026-05-10, blocking cached torrents tagged with WEB-DL, AMZN, NF, YTS, RARBG, and EZTV keywords. RD returns `infringing_file` responses instead of playable links for these files.
    - Impact on the homelab Stremio experience: 50%+ of Torrentio search results became dead links
    - Why a filtering proxy is the right solution: AIOStreams intercepts addon responses before they reach the Stremio client and removes filtered results before display
    - Constraint: AIOStreams SECRET_KEY is immutable after first pod startup — if changed, all saved user configs are invalidated
    - Constraint: deployment is intranet-only (MetalLB LoadBalancer; no public DNS or Traefik ingress)

    **## Decision**
    Bold statement: "Deploy self-hosted AIOStreams v2.29.5 on K3s, managed by ArgoCD, to filter Real-Debrid-blocked content from Stremio search results before they surface to the user."

    Brief rationale: AIOStreams is classified as a K3s application per ADR-016 (user-facing app; no other service depends on it). It is installed via GitOps (ArgoCD watching `kubernetes/aiostreams/`) and uses OpenBao-backed ExternalSecret for credential management, consistent with homelab patterns.

    **## Alternatives Considered**

    Three alternatives explicitly addressed (D-08):

    **1. Comet addon**
    - What it is: Alternative filtering addon for Stremio with Real-Debrid support
    - Why not chosen: Less mature than AIOStreams; smaller community; fewer debrid provider integrations; limited regex filtering capability compared to AIOStreams' WHITELISTED_REGEX_PATTERNS system

    **2. ElfHosted hosted AIOStreams**
    - What it is: Managed SaaS offering of AIOStreams on ElfHosted's infrastructure
    - Why not chosen: ElfHosted hosted instances sometimes disable Torrentio for licensing reasons, removing a key content source; self-hosted preserves full Torrentio access and intranet isolation; avoids ongoing subscription cost for a single-user homelab

    **3. Switch debrid providers (TorBox, Usenet)**
    - What it is: Migrating from Real-Debrid to a provider that does not implement the May 2026 blocking
    - Why not chosen: Requires API key rotation and workflow changes across all Stremio addons; TorBox is less tested in this homelab; Usenet has slower upload performance for recent releases; Real-Debrid with filtering is viable and preserves the existing investment

    **## Consequences**

    Positive:
    - Stremio search results no longer show dead-link WEB-DL/AMZN/YTS/RARBG entries
    - AIOStreams UI provides centralized control over debrid providers, addon sources, and regex filter patterns
    - GitOps-managed deployment (ArgoCD + ExternalSecret) follows established homelab patterns

    Ongoing operational:
    - Regex patterns (WHITELISTED_REGEX_PATTERNS ConfigMap) must be reviewed quarterly as Real-Debrid's block list evolves; update in kubernetes/aiostreams/configmap.yaml and trigger ArgoCD sync
    - SECRET_KEY is immutable: generated once during Phase 1 provisioning; never rotated; if the OpenBao secret is lost, a new deployment requires wiping the SQLite database and re-onboarding users
    - Intranet-only exposure is an accepted constraint: AIOStreams is reachable at http://192.168.1.205:3000 on LAN only; external internet access would require Traefik IngressRoute and internal DNS (deferred to PLAT-01/PLAT-02)
    - SQLite persistence (PVC at /app/data) is adequate for single-user homelab; multi-replica HA would require PostgreSQL (deferred to RES-02)
