    **Title:** "# Filter Validation Procedure"

    **Opening context (2-3 sentences):** This is a one-time validation confirming the AIOStreams regex exclusion filter is active and blocking WEB-DL, YTS, AMZN, DSNP, RARBG, and EZTV-tagged streams from appearing in Stremio search results. Complete AFTER setup-aiostreams.md (filter must be activated first).

    **## Prerequisites:**
    - AIOStreams running at http://192.168.1.205:3000
    - Torrentio addon installed and visible in AIOStreams Addons → Installed tab
    - Regex exclusion filter activated in AIOStreams Filters → Regex Patterns
    - AIOStreams added as a Stremio addon source (http://192.168.1.205:3000/manifest.json)
    - See homelab-knowledge/runbooks/setup-aiostreams.md for all of the above

    **## Procedure:**

    ### Step 1: Open Stremio and search for known WEB-DL content
    Use these specific search terms — all have widely available WEB-DL, AMZN, and YTS-tagged versions in Torrentio:
    - TV shows: "Breaking Bad", "The Office", "Game of Thrones"
    - Movies: "Oppenheimer", "Dune Part Two", "The Godfather"

    Search for any of the above in Stremio. Wait for results to load (may take 5-10 seconds as AIOStreams queries Torrentio).

    ### Step 2: Inspect stream results
    For each search result that shows streams, review the stream source labels:
    - **Expected (filter active):** No stream titles or labels containing WEB-DL, AMZN, DSNP, YTS, RARBG, or EZTV
    - **Not expected:** 1080p WEB-DL, AMZN WEB-DL, YTS.MX releases, EZTV releases

    ### Step 3: Optional baseline comparison
    To confirm AIOStreams is the source of filtering (not a Torrentio outage):
    Temporarily add vanilla Torrentio directly in Stremio: https://torrentio.strem.fun/manifest.json
    Search the same content — WEB-DL/YTS entries SHOULD appear in vanilla Torrentio results.
    Remove vanilla Torrentio after verification.

    ### Step 4: Cache-clear if results are stale
    If Stremio still shows WEB-DL results after confirming filter is active in AIOStreams:
    In Stremio: Settings → Addons → Remove the AIOStreams source → Re-add http://192.168.1.205:3000/manifest.json
    This forces Stremio to refresh addon state and re-fetch from AIOStreams.

    **## Pass Criteria (all must be true):**
    - At least one search returns results (pod is healthy, addon connectivity OK)
    - No stream titles or labels contain: WEB-DL, AMZN, DSNP, YTS, RARBG, EZTV
    - Vanilla Torrentio comparison (Step 3) shows those tags ARE present in unfiltered results

    **## Fail Criteria and Remediation:**
    Table with: Symptom | Likely cause | Remediation
    - Zero results from any search | Pod not responding or addon connectivity failure | Check `kubectl logs -n aiostreams deployment/aiostreams --tail=30`; verify http://192.168.1.205:3000/api/v1/status returns 200
    - WEB-DL entries still appear in results | Filter not activated or regex pattern not applied | Navigate AIOStreams Filters → Regex Patterns; confirm toggle is enabled; verify WHITELISTED_REGEX_PATTERNS env: `kubectl exec -n aiostreams deployment/aiostreams -- env | grep WHITELISTED`
    - Real-Debrid streams return "error" or "unavailable" | RD API key invalid or ESO sync failed | Check Services menu in AIOStreams; run `kubectl get externalsecret -n aiostreams aiostreams-secret` for sync status
    - Stremio shows stale results after filter activated | Stremio addon cache | Remove/re-add AIOStreams addon source (Step 4)
